## Logos Harmoni (Jardins, Árbore, Vale, Essenza)

`logo-01.svg` é preto (`#1d1d1b`), para fundo claro. `logo-02.svg` é laranja + creme (`#f18d5a` + `#f7e6d4`), para fundo escuro. `logo-03.svg` é o colorido principal. Conferido pelas cores dentro de cada SVG.

## Avisos

- Os renders `HARMONI-01-*` são do **Harmoni Vinhedos**. O HTML da vitrine os reutiliza como provisórios nos outros Harmonis: manter só como placeholder rotulado.
- Só Vinhedos tem perspectivas, implantação e localização. Jardins, Árbore, Vale e Essenza têm apenas logo.
- `vinhedos/perspectivas/portico.webp` é a versão 1536px; `portico-original.webp` é a maior.
- Todas as fotos dos Harmonis são provisórias: usam renders do Vinhedos e serão substituídas. Fotos institucionais da Nova Harmonia em `nova-harmonia/institucional/` (também provisórias).
